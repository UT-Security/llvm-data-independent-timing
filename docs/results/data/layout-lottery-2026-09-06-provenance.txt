layout-decomp-2026-09-06.csv
    6 arms x 5 benchmarks x 2 switch models = 60 cells. base / rt / notwinnop /
    notwin / taintnop / taint. All gates pass. The 30 cells shared with
    paper_experiments/09-libsodium-cio-parity/data/gem5_apple_bracket_2026-09-06.csv
    reproduce identical to the decimal in a different work directory.

layout-relink-base-2026-09-06.csv
    The null control on the UNHARDENED library: 20 relink offsets
    (0,4,8,12,16,24,32,48,64,96,128,256,512,1k,2k,4k,8k,16k,32k,64k bytes) x 5
    benchmarks, spec only (no msr DIT executes, so the switch model is
    irrelevant). Committed instruction count identical across every offset.

layout-relink-taint-2026-09-06.csv
    The same 12 small offsets on the taintnop library, so the two arms can be
    compared as ensembles rather than as one A/B draw.

layout-relink-align64-2026-09-06.csv
    The same 12 offsets on a library built with
    -mllvm -align-all-nofallthru-blocks=6.

layout-decomp-2026-09-06-counters.csv
